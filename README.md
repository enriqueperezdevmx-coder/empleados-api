# Empleados API

API REST para administrar empleados, construida paso a paso en la Academia Java CDMX (Semana 3, del 24 al 26 de septiembre de 2026).

Alumno: Enrique Pérez Sánchez

## Tecnologías

* Java 17
* Spring Boot 3.4.x
* Spring Data JPA (Hibernate)
* Bean Validation
* MySQL 8.4 en Docker
* springdoc-openapi (Swagger)
* WSL2 con Ubuntu 24.04

## Cómo levantarla

```bash
docker compose up -d
./mvnw spring-boot:run
